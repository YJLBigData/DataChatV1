# 市场情报 Skill

> 竞品动态、价格监控、市场份额、行业趋势。严观澜专项。

## 触发词

| 用户表达 | 说明 |
|---------|------|
| "竞品有什么动作" | 竞品监控 |
| "价格异常"、"促销力度" | 价格监控 |
| "市场份额变化" | 份额分析 |
| "行业趋势"、"出生率" | 行业研判 |

## 输入

| 参数 | 必选 | 说明 |
|------|------|------|
| focus | 否 | 分析重点（竞品/价格/份额/趋势） |
| competitors | 否 | 竞品名称列表 |
| region | 否 | 区域范围 |

## 输出

市场情报分析（待填充具体格式）。

## SOP（5步，待填充）

1. **意图解析**：确定分析重点（竞品/价格/份额/趋势）
2. **内部数据**：调用 datachat-query 获取份额/价格数据（有限）
3. **外部搜索**：websearch 获取竞品和行业最新动态
4. **综合研判**：内外部信息交叉验证
5. **输出**：结构化市场情报 + 信息来源标注

## 依赖

- datachat-query skill（内部数据）
- websearch（外部信息）

## 数据源

- 内部：AnalyticDB 中份额/价格数据有限
- 外部：Web 搜索为主要信息源
- 标注来源和时效性

## 注意事项

- 竞品信息需标注来源和可靠性
- 区分"已发生事实"和"趋势预判"
- 市场份额有不同口径（尼尔森/凯度/内部），需明确
- 当前内部数据源缺竞争对手数据，主要依赖 websearch
