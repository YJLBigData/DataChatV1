# 渠道诊断 Skill

> 渠道效率、铺货率、动销率、门店表现。路通达专项。

## 触发词

| 用户表达 | 说明 |
|---------|------|
| "渠道效率"、"哪个渠道有问题" | 渠道效率分析 |
| "铺货率"、"覆盖" | 铺货覆盖分析 |
| "动销率"、"铺了不动" | 动销分析 |
| "门店表现"、"单店产出" | 门店分析 |

## 输入

| 参数 | 必选 | 说明 |
|------|------|------|
| entity | 否 | 区域/渠道名称 |
| time_range | 否 | 时间范围（默认当月） |
| focus | 否 | 分析重点（效率/铺货/动销/门店） |

## 输出

结构化渠道诊断结果（待填充具体格式）。

## SOP（5步，待填充）

1. **意图解析**：确定分析重点（效率/铺货/动销）
2. **数据拉取**：调用 datachat-query 获取渠道数据
3. **渠道效率计算**：单店产出、动销率、库存周转
4. **异常识别**：铺货率↑动销率↓ 等危险信号
5. **诊断输出**：结构化结论 + 建议

## 依赖

- datachat-query skill
- data-query-general skill

## 数据源

当前 AnalyticDB 中渠道粒度数据有限，主要从 dan_summary_df 的 big_system_channel_name 维度分析。
铺货率/动销率/门店级别数据待接入。

## 注意事项

- KSC东区/西区是独立渠道，不得合并
- 渠道占比是零和博弈，报喜必须报忧
- 当前数据源缺少门店级别数据，需标注边界
