# 知识审计 Skill (feihe-decision-audit)

> 纪鉴明的专用 Skill，覆盖知识库质量审计、Skill 注册审计、经验记录。

## 触发词
| 场景 | 动作 |
|------|------|
| 新 Skill 注入评估 | 执行 Skill 质量审计 |
| 知识库定期巡检 | 执行知识库质量审计 |
| 会话结束记录 | 执行经验沉淀 |

## 输入
- 审计对象：Skill 路径 / 知识库文件 / 会话产出
- 审计类型：质量评估 / 注册合规 / 经验记录

## 输出
- 审计报告（markdown格式）

## SOP（5步）

### 步骤1：确认审计范围
- 明确审计对象和类型
- 确认审计标准（K1-K6 参照完整性、Skill 结构合规性）

### 步骤2：执行审计

#### Skill 质量审计清单
| 检查项 | 标准 |
|--------|------|
| SKILL.md 结构 | 有触发词+输入输出+SOP+约束 |
| 参照完整性 | 引用的知识库文件是否存在 |
| 数据表引用 | 引用的表名是否在 K1 中 |
| 输出格式 | 是否符合 K5 |
| 与注册表一致 | Skill 名和路径是否与 feihe-decision 注册表一致 |

#### 知识库审计清单
| 检查项 | 标准 |
|--------|------|
| 枚举值完整性 | 维度枚举是否与数据库实际一致 |
| 口径标注 | 每个指标是否有 K2 口径定义 |
| 时效性 | 最近更新日期是否在30天内 |

### 步骤3：记录发现
- 合规项：直接记录
- 不合规项：标注风险等级（P0/P1/P2）

### 步骤4：输出审计报告
```markdown
[知识审计报告]
### 审计对象
{Skill名/知识库文件名}
### 审计结论
合规 / 标注风险 / 不合规
### 发现清单
| # | 类型 | 风险 | 说明 |
|---|------|------|------|
| 1 | ... | P0/P1/P2 | ... |
### 建议
{修正建议}
```

### 步骤5：经验沉淀
- 会话中有价值的分析思路 → 记入 K3 对应领域
- 编排调度经验 → 记入 K6
- 数据口径发现 → 更新 K2

## 约束
- 只做诊断+记录，不做修改类运维
- 不修改 Skill 代码或知识库内容
- 发现问题后通知主理人决策
