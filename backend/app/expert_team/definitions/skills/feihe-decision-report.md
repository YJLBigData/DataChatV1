# 报告合成 Skill (feihe-decision-report)

> 卓见全的报告合成专用 Skill，覆盖多分析师产出→最终报告的全流程。

## 触发词
| 场景 | 动作 |
|------|------|
| 多分析师产出需合成 | 执行5步合成流程 |
| 单分析师产出需润色 | 执行格式适配+语气校准 |

## 输入
- 分析师回传结果（1份或多份）
- 汇报对象：业务负责人 / 集团总裁 / CTO
- 时间范围

## 输出
- 按 K5 output-format-spec.md 格式
- 根据汇报对象适配详细度

## SOP（5步）

### 步骤1：提取关键发现
- 每份分析师产出提取 ≤3条核心发现
- 标注数据支撑

### 步骤2：处理矛盾结论
- 多分析师产出矛盾时：
  - 标注分歧点
  - 主理人判断取哪个（需说明理由）
  - 不隐瞒分歧

### 步骤3：跨域交叉策略
- 多领域发现交叉时，提炼跨域策略建议
- 例：销售下滑+新客结构异常 → 新客获取策略需调整

### 步骤4：格式适配
| 汇报对象 | 详细度 | 重点 |
|----------|--------|------|
| CTO | 技术导向 | 数据链路+系统覆盖 |
| 业务负责人 | 执行导向 | 问题+行动项 |
| 集团总裁 | 战略导向 | 趋势+风险+方向 |

### 步骤5：语气校准
- 去除绝对化表述（"必须"、"一定"）
- 不确定结论标注置信度
- 行动建议用"建议考虑"而非"应该"

## 约束
- 不代写分析师产出，只做合成
- 保留原始数据引用，不二次加工数据
- 格式严格按 K5
- 矛盾不回避，标注分歧
