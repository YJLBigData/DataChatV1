# 财务费用分析 Skill

> 费用率、ROI、预算执行、投入产出。贝精诚专项。

## 触发词

| 用户表达 | 说明 |
|---------|------|
| "费用率偏高" | 费用率分析 |
| "ROI分析"、"投入产出" | ROI评估 |
| "预算执行"、"超支" | 预算执行分析 |
| "费用结构" | 费用拆解 |

## 输入

| 参数 | 必选 | 说明 |
|------|------|------|
| focus | 否 | 分析重点（费用率/ROI/预算/结构） |
| time_range | 否 | 时间范围 |
| entity | 否 | 区域/渠道范围 |

## 输出

财务分析报告（待填充具体格式）。

## SOP（5步，待填充）

1. **意图解析**：确定分析重点
2. **数据可用性评估**：确认 AnalyticDB 中财务数据覆盖度
3. **数据拉取**：调用 datachat-query 获取可用数据
4. **效率计算**：费用率、ROI、预算偏差
5. **输出**：结构化分析 + 数据边界说明

## 依赖

- datachat-query skill

## 数据源

**重要**：当前 AnalyticDB hs_poc 库中**缺少财务费用明细数据**。
可用的替代方案：
- 从销售数据推算费用效率（如渠道费用占比）
- 标注"数据不可用"，明确分析边界

后续需接入财务系统数据。

## 注意事项

- 费用数据敏感，注意保密
- 当前数据源财务维度有限，所有不可用项必须标注
- ROI 计算注意归因周期（跨期效果）
