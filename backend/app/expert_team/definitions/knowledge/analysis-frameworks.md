## #sales 销售（齐增辉）

### 常用分析维度
- 达成：达成率/差距/差距贡献
- 品类：品类贡献率/品类结构变化
- 区域：大区/省区/城市对比
- 渠道：大系统渠道贡献
- 时间：同环比/趋势/累计

### 常用方法
1. **归因分析**：销售额变化 = 量差 × 价差 → 哪个变了
2. **结构拆分**：按品类/区域/渠道拆分看贡献率变化
3. **对比分析**：同环比/目标对比/区域排名
4. **红绿灯诊断**：环比 < 0.9 或达成率 < 75% 标黄，< 0.8 或 < 65% 标红

### 典型分析步骤（区域销售诊断）
1. 全局概览：总销售额 + 环比 + 同比 + 达成率
2. 区域红绿灯：按大区看环比/达成率，找异常
3. 异常深挖：对异常区域拆分到省区/渠道/品类
4. 根因定位：量差 vs 价差，新客 vs 复购
5. 结论 + 建议

## #channel 渠道（路通达）

### 常用分析维度
- 渠道类型：RKSC/KSC/常规渠道
- 铺货：铺货率/动销率/缺货率
- 效率：单店产出/渠道坪效
- 结构：渠道贡献变化/渠道品类结构

### 常用方法
1. **铺货分析**：应铺门店数 vs 实铺 vs 动销
2. **效率对比**：不同渠道单店产出对比
3. **结构变迁**：渠道占比变化趋势
4. **缺货预警**：连续N月无出货门店标记

### 典型分析步骤（渠道诊断）
1. 渠道概览：各渠道销售额 + 占比 + 变化
2. 铺货健康：铺货率/动销率/缺货率
3. 效率对比：单店产出排名/异常
4. 结构判断：渠道转移趋势
5. 建议

## #user-ops 用户运营（甄客来）

### 常用分析维度
- 时间：同比/环比/趋势
- 结构：段位/渠道/区域
- 转化：漏斗（潜客→新客→复购）/复购周期

### 常用方法
1. **漏斗分析**：潜客→新客→复购各环节转化率
2. **同期群分析**：同一批新客后续复购率跟踪
3. **结构拆分**：按段位拆分看新客结构健康度
4. **转化率对比**：不同渠道/区域新客转化率对比

### 典型分析步骤（新客诊断）
1. 全局新客概览：总量 + 同比 + 结构
2. 段位结构：1段/2段/3段占比是否健康
3. 转化漏斗：潜客→新客→复购
4. 渠道/区域差异：哪里新客表现好/差
5. 结论 + 建议

## #market 市场（严观澜）

### 常用分析维度
- 份额：飞鹤份额 vs 竞品
- 价格：终端价/促销价/价格弹性
- 趋势：行业大盘/品类趋势
- 政策：注册制/广告法/跨境政策

### 常用方法
1. **份额估算**：基于出货数据推算市占率
2. **价格监测**：终端价波动 + 促销频次
3. **趋势研判**：行业数据 + 季节性规律
4. **政策解读**：新政策对品类/渠道的影响

### 典型分析步骤（市场监测）
1. 行业大盘：出生率/行业规模/品类趋势
2. 竞争格局：飞鹤份额变化 + 竞品动态
3. 价格体系：终端价/促销情况
4. 政策影响：近期政策对业务的影响评估
5. 建议

## #finance 财务（贝精诚）

### 常用分析维度
- 费用：营销费/渠道费/人力费
- 利润：利润额/利润率/毛利
- 效率：费效比/ROI/人效
- 达成：费用预算达成率/利润目标达成率

### 常用方法
1. **费用归因**：费用变化 = 哪项费用多了/少了
2. **费效对比**：投入产出比变化 + 渠道/活动维度
3. **预算偏差**：实际 vs 预算差异分析
4. **利润拆分**：收入端 - 成本端 - 费用端

### 典型分析步骤（费用分析）
1. 费用概览：总费用 + 费用率 + 同比
2. 预算偏差：实际 vs 预算差异
3. 费效对比：各渠道/活动 ROI
4. 利润影响：费用变化对利润的影响
5. 建议
