# 输出格式规范 (K5)

> 3种标准输出格式：快查询 / 分析报告 / 检核报告。
> 所有分析师和取数分析师必须按此格式输出。
> 最后更新：2026-06-17

---

## 格式一：快查询输出（速捷用）

用于简单取数查询，用户只需要数据本身。

```markdown
[数据查询结果]

### 核心指标摘要
- {指标1}：{值}（同比 {X%} / 环比 {X%}）
- {指标2}：{值}（同比 {X%} / 环比 {X%}）
- ...（3-5个）

### 数据表
| 维度 | {指标1} | {指标2} | ... |
|------|---------|---------|-----|
| {行1} | {值} | {值} | ... |
| {行2} | {值} | {值} | ... |

### 元信息
- 数据时间范围：YYYY-MM ~ YYYY-MM
- 数据更新时间：YYYY-MM-DD
- 查询表：{表名}
- 权限范围：{全国/大区/省区}
```

---

## 格式二：分析报告（5个分析师用）

用于深度分析场景，需要结论+数据支撑+建议。

```markdown
[{领域}分析报告]

### 核心发现（≤3条）
1. **{结论1}**（数据支撑：{XXX} 同比 {X%}）
2. **{结论2}**（数据支撑：{XXX}）
3. **{结论3}**

### 详细分析

#### 步骤1：{分析步骤名}
{分析过程，含数据引用}

#### 步骤2：{分析步骤名}
{分析过程，含数据引用}

#### ...（按方法论步骤推进）

### 建议方向（≤3条）
1. {可操作建议1}
2. {可操作建议2}
3. {可操作建议3}

### 数据置信度
- 置信度：{高/中/低}
- 原因：{说明数据口径或缺失情况}

### 引用指标清单
- {指标1}（口径：见 data-dictionary §{XX}）
- {指标2}
- ...
```

## 格式三：检核报告（查实真用）

用于数据质量检核和多分析师产出一致性检核。

```markdown
[数据检核报告]

### 检核结论
{通过 / 标注风险通过 / 不通过}

### Phase A 结果检核
| 检核项 | 结果 | 说明 |
|--------|------|------|
| SQL语法 | ✓/✗ | {详情} |
| 计算逻辑 | ✓/✗ | {详情} |
| 同环比 | ✓/✗ | {详情} |
| 数量级 | ✓/✗ | {详情} |
| 时效性 | ✓/✗ | {详情} |

### Phase B 异常检查
| 检核项 | 结果 | 说明 |
|--------|------|------|
| 空值率 | ✓/✗ | {详情} |
| 枚举合法 | ✓/✗ | {详情} |
| 口径一致 | ✓/✗ | {详情} |
| 跨分析师一致 | ✓/✗ | {仅多分析师场景} |

### 修正建议
{如不通过，列出具体修正项}
```

---

## 通用规则

1. **数据引用**：所有结论必须附数据出处（表名+字段+时间范围）
2. **单位**：金额统一用"万元"（除特别说明外），人数用"人"，比率用"%"
3. **时间**：默认用"YYYY年MM月"格式，不写"本月/上月"
4. **排名**：用"第N名/共M个"，不单写"第N"
5. **同比/环比**：必须标注口径（同比=去年同月，环比=本月日均/近3月日均）
6. **缺失数据**：明确标注"暂无数据"，不填0或留空
